## 1.14 更新要点

- **网页替换更稳定**：改善动态提示语、开放 Shadow DOM 及同源嵌套页面的处理；已有网页收到新规则后从原文重算，暂停或清空时恢复受管理的内容。
- **优先级统一**：应用规则优先于全局规则，各组按列表顺序执行；新增冲突提示，优化拖拽排序并避免重复替换。
- **规则编辑与恢复更可靠**：修复新增样式丢失、自定义时间变量缓存、最后一批停用规则清理等问题；输入或保存出错时保留编辑内容，导入前完整检查备份。
- **首页保持原有三灯**：通道 / 取词 / Root，第一个仍表示 LSPosed 服务连接状态；已取消打开 GText 时的规则升级提醒弹窗。

**升级到 1.14 后，请先打开一次 GText，再重启目标应用一次。** 旧规则顺序会保留，但重叠规则的结果可能因优先级调整而变化，详见[规则优先级与冲突](#规则优先级与冲突)。完整变更见 [CHANGELOG.md](CHANGELOG.md)。

## 功能介绍

GText 是一款基于 LSPosed 框架的 Android 文字替换模块，用于调整应用界面的文案和显示效果。替换发生在本机，**界面上的替换文字不代表服务器记录、商品价格等实际业务数据发生变化**。可替换的范围取决于页面使用的文字渲染方式。

### 核心特性

| 特性 | 说明 |
|------|------|
| 🎯 **字面文本替换** | 按输入原文匹配文本中的相同片段，例如「订单」也会命中「订单详情」 |
| 🔣 **正则表达式** | 批量命中相似文字，如 `\d+分钟前` 一条规则替换所有"N分钟前" |
| 🔡 **忽略大小写** | 英文规则不区分大小写，可与正则叠加 |
| ⚡ **规则热更新** | 接收新配置后，网页 DOM 重新计算；原生文字在后续赋值/渲染时更新 |
| 🌐 **全局规则** | 一条规则对所有已添加应用生效，无需逐个添加 |
| 🖥️ **系统界面** | 支持替换状态栏、设置等系统界面文字（配合作用域） |
| 👆 **屏幕取词** | 无障碍悬浮取词：在目标应用中点选文字直接创建规则 |
| 🧭 **替换范围** | 按类别控制每个应用参与替换的范围：文字界面 / 菜单弹窗 / 通知媒体 / H5 / 自绘 |
| 🧠 **深度模式** | 额外覆盖资源字符串（Resources.getString）等深层入口，可随时关闭 |
| 🧹 **批量操作** | 一键全部启用 / 全部停用 / 清理停用规则 / 清空规则 |
| 🚫 **一键暂停** | 快捷设置磁贴保存暂停/恢复状态；接收后按通道更新 |
| 🔀 **优先级排序** | 应用规则优先，各组按列表顺序匹配；长按拖拽可调整组内顺序 |
| 🧩 **冲突提示** | 列表和编辑器提示重复或可能重叠的规则，允许继续保存 |
| 🔍 **拼音搜索** | 主页支持全拼/首字母搜索（搜 "jd" 找到"京东"），命中高亮 |
| 🔄 **检查更新** | 读取 GitHub 最新 Release 并展示版本、附件与更新日志；启动时 6 小时自动检查一次 |
| 🔬 **页面自检** | 根据可读节点分析页面特征，辅助判断可尝试的替换通道 |
| 🅰 **字母分组** | 首页按拼音首字母分组，右侧字母条快速定位 |
| 🎨 **替换样式** | 单条规则可设粗体 / 斜体 / 红色 |
| 🕒 **动态变量** | 支持日期、时间、随机数及自定义日期时间格式，在重新匹配时计算 |
| 🔢 **捕获组** | 正则替换支持 `$1`~`$9` 引用分组 |
| 💾 **备份恢复** | 备份应用规则、全局规则及替换相关设置，恢复前完整校验 |
| 🔁 **重启应用** | Root 下重启桌面/系统界面等系统应用，无需重启手机 |
| 🙈 **隐藏桌面图标** | 隐藏后替换功能照常运行；可从 LSPosed 管理器长按模块 →「模块设置」重新打开并恢复 |
| 🚫 **生效范围可控** | 单条规则开关、单应用总开关，全局规则只对已添加应用生效 |

### 应用场景

- 🌐 **本地化翻译**：将应用中的英文替换为中文或其他语言
- ✏️ **文本修正**：修正应用中的错别字或不当表述
- 🎨 **个性化定制**：自定义应用中的文字显示内容
- 🔧 **文案精简**：缩短冗长提示、调整界面用词

### 当前方案不覆盖的情况

| 引擎 | 典型页面 | 原因 |
|------|---------|------|
| Flutter / FlutterBoost | 闲鱼「订单列表/详情」等 | 文本由 Flutter 引擎（Skia）在 C++ 层自绘，Java 层无拦截点 |
| Unicorn 等自绘引擎 | 淘宝「订单详情」 | native Skia 绘制，文本不经过任何 Java API |
| 游戏引擎文字 / 视频硬字幕 | 游戏画面、已经压入视频画面的字幕 | 文字已由引擎或画面像素呈现，没有可替换的 Java 文本入口 |
| WebView 画布模式 | 在线文档等 | Canvas 渲染，DOM 中无文本节点 |

**初步排查**：可用「页面自检」，或通过 `adb shell dumpsys activity top` 查看视图树。若页面主要由 `SurfaceView` / `FlutterView` 构成，可能使用引擎自绘；这只是判断线索，不能据此认定整页所有文字都能或都不能替换。

## 安装与激活

1. **安装模块**
   - 从 [Releases](https://github.com/comewhy/com.comewhy.gtext/releases) 下载最新 APK 安装

2. **激活模块**
   - 打开 LSPosed 管理器 → 模块列表 → 勾选启用 GText

3. **授权 Root（建议但非必需）**
   - 已有可用 LSPosed 服务通道时，GText 无需额外 Root 授权即可同步规则。
   - 授权 Root 可额外启用：文件兜底写入、「重启该应用」、无障碍服务自动恢复。
   - 首次安装或更新后首次打开 GText，未授权 Root 时仍会显示原有 Root 说明弹窗，15 秒倒计时结束后可关闭；同一版本只提示一次。

4. **配置作用域**
   - 在 GText 中添加应用时会**自动弹出 LSPosed 作用域申请**，一键确认即可
   - 也可稍后在 LSPosed 中手动勾选

5. **重新打开目标应用**
   - 首次配置作用域或升级 GText 后，重启目标应用一次，加载对应 Hook。
   - 后续普通规则修改通过热更新同步，已有文字如何更新见[已有页面的更新与暂停恢复](#已有页面的更新与暂停恢复)。

## 使用说明

### 添加替换规则

1. 打开 GText，点右下角 **➕** 选择目标应用
2. 进入应用规则页，点击 **➕** 添加规则
3. 填写 **原文**（应用里显示的文字）和 **替换文**（想改成的内容）
4. 按需开启 **正则表达式** / **忽略大小写** 开关
5. 保存后，配置会在后台同步；目标应用接收后，按所在通道更新文字

普通规则采用**字面包含匹配**：原文填写 `订单`，也会替换 `订单详情` 中的 `订单`。若只希望整段等于 `订单` 时替换，可开启正则并填写 `^订单$`。

当前编辑器要求原文和替换文均非空，保存时会去除首尾空格。输入无效或保存失败时，已填写内容会保留。

**替换文支持的语法**

| 语法 | 说明 | 示例 |
|------|------|------|
| `$1`~`$9` | 正则捕获组引用 | 原文 `(\d+)元` → 替换文 `$1元红包` |
| `{date}` | 当前日期 | `2026-10-28` |
| `{time}` | 当前时间 | `20:15` |
| `{datetime}` | 日期 + 时间 | `2026-10-28 20:15` |
| `{random}` | 随机四位数 | `3167` |
| `{date:格式}` | 自定义日期格式 | `{date:yyyy年M月d日}` → `2026年10月28日` |
| `{time:格式}` | 自定义时间格式 | `{time:HH:mm:ss}` → `20:15:03` |
| `{datetime:格式}` | 自定义日期时间格式 | `{datetime:MM/dd HH:mm}` → `10/28 20:15` |

变量在下一次匹配时展开，静止页面不会因为使用 `{time:HH:mm:ss}` 就自动每秒刷新。网页常用格式支持 `yyyy`、`yy`、`M` / `MM`、`d` / `dd`、`H` / `HH`、`h` / `hh`、`m` / `mm`、`s` / `ss`；其他格式及高级正则语法的兼容性可能与原生通道不同。

**替换样式**：规则编辑页可选择「默认 / 粗体 / 斜体 / 红色」，让**替换后的文字**有视觉强调（不改变被替换前的原文）。

> 样式生效范围：只有目标控件以富文本（Spannable）方式渲染时颜色/粗斜体才可见——
> ✅ **支持样式的主要通道**：以 Spannable 渲染的原生控件与通知文字；目标应用可能自行调整样式
> ⚠️ **仅替换文字、样式丢失**：走纯字符串通道的地方，如深度模式的 `Resources.getString`、媒体元数据（歌名/歌手）、菜单 `Menu.add`、最近任务卡片标签
> **仅替换文字，不附加规则样式**：WebView 网页内容、Canvas 自绘文字
>
> 可先在普通页面文字上验证；文字替换成功与粗体、颜色是否呈现，需要分别判断。

**宽松匹配（自动兜底）**：有些页面文字“看起来一样却匹配不上”，可能夹带零宽字符、全角字符或 NBSP 空格。GText 先按原文正常匹配，**只有整段文本没有命中任何规则时**，才尝试去除零宽字符、统一全半角和空格后再匹配，并将命中位置映射回原文。

| 编辑 / 删除 | 规则卡片右侧按钮 |
| 搜索 | 各页顶部搜索框；主页支持拼音/首字母 |
| 冲突提示 | 列表和编辑器提示确定重复、字面包含、同模式同选项正则；可继续保存 |
| 批量操作 | 规则页菜单 →「批量操作」：全部启用 / 全部停用 / 删除已停用的规则 / 清空所有规则 |
| 长按卡片 | 复制该条规则原文 |
| 撤销删除 | 删除规则 / 应用后，底部提示条点「撤销」恢复 |
| 搜索高亮 | 规则列表搜索时命中文字高亮 |

### 规则优先级与冲突

本版本统一采用以下顺序：**应用规则在前，全局规则在后；每组严格按列表顺序执行**。普通规则、忽略大小写规则与正则规则具有同等优先级。先命中的原文区间归先执行的规则，后续规则只能处理尚未占用的区间；替换出的文字不会再次参与本轮替换。可以长按拖动调整组内顺序。

例如应用规则 `订单 → 我的订单` 与全局规则 `订单 → Order` 同时存在时，应用规则生效；若同组前面的 `订单` 先命中，后面的 `订单详情` 不会覆盖这段文字。

列表与编辑器会提示确定重复、字面原文包含关系、以及模式和选项完全相同的正则规则。提示不会阻止保存，也不会自动改变顺序。它不判断任意两段不同正则是否相交；没有提示并不代表所有输入下都不会重叠。

**升级说明：旧版本依赖“普通规则优先”或“全局同原文覆盖”的配置，结果可能改变。请检查冲突提示并按需要排序，随后重启目标应用一次加载新引擎。** 保存失败或输入无效时，编辑器会保留尚未保存的内容。

### 替换范围（每应用通道开关）

应用规则页菜单 →「替换范围」，可分别控制该应用哪些类别参与替换：

| 范围 | 覆盖内容 |
|------|----------|
| 文字界面 | 文本框、标题、对话框等常规文字 |
| 菜单与列表弹窗 | 下拉菜单、悬浮菜单、列表式弹窗条目 |
| 通知、媒体、快捷菜单 | 通知文字、歌名歌手、长按图标菜单 |
| 网页 H5 | 网页文本、输入框提示、页面标题 |
| 自绘文字 | Canvas 绘制的文字等 |

默认全部开启。某类文字导致异常时可单独关闭；**改动需重启目标应用**才完全生效（Hook 按范围安装）。

### 设置页

右上角菜单 →「**设置**」，集中管理全部开关与数据操作：

| 分区 | 内容 |
|------|------|
| 生效设置 | **暂停全部替换**（与下拉磁贴双向同步）、**启动时显示激活提示**、**深度模式** |
| 数据管理 | **备份配置**、**恢复配置** |
| 其他 | **检查更新**（读取 GitHub 最新版本，含更新日志与下载入口）、**隐藏桌面图标**、**关于 GText**（版本、简介与联系方式直接显示在标题下方，Telegram 链接可点击） |

> **深度模式**（默认开启）：额外拦截 `Resources.getString` 等资源字符串入口，能覆盖更多界面文字。它会更深地介入应用逻辑，个别应用如出现显示或参数异常，先关闭它并重启应用。

### 首页信号灯与启动提示

首页保持原有的一行统计和三个信号灯，搜索框默认收起，点击工具栏放大镜展开。

| 信号灯 | 表示的状态 | 点击后的内容 |
|------|------|------|
| 通道 | LSPosed 官方服务是否连接 | 原有的规则同步通道说明 |
| 取词 | 屏幕取词无障碍服务是否连接 | 取词说明或恢复服务入口 |
| Root | GText 是否取得 Root 授权 | Root 状态与授权说明 |

绿色表示已连接或已授权，红色表示未连接或未授权；检测过程中可能暂时显示灰色。**第一个灯只表示通道连接状态，不等于所有目标应用都已加载新规则。**

打开 GText 时已取消规则升级提醒弹窗。原有 Root 说明仍按安装版本提示；设置中的「启动时显示激活提示」控制的是目标应用启动时的 GText 激活提示。

### 全局规则

首页列表顶部「全局规则」卡片：对所有**已添加且未停用**的应用统一生效，适合替换多个应用中相同的文字。
> 只在 GText 中添加过的应用才会应用全局规则；仅勾选 LSPosed 作用域但未添加的应用不会被替换。

### 页面自检

规则页菜单 →「页面自检」→ 切到目标应用 → 点顶部「自检」：统计可读节点及 WebView / Compose / Flutter / SurfaceView 等特征，给出可尝试的通道建议。自检用于辅助排查，不代表已经验证规则命中或整页兼容。

### 已有页面的更新与暂停恢复

本版本会为已处理的网页 DOM 保留原文。网页接收新配置后，已有文字、标题和受支持属性会从原文重新计算；暂停、停用或清空规则时恢复仍由 GText 管理的值。网页自己更新文字时，以网页的新值为准，避免恢复过期内容。

覆盖普通 DOM 文本、页面标题、`placeholder`、`alt`、`title`、`aria-label`、按钮显示值、同源 iframe 和开放 Shadow DOM；页面新增文字或相关属性发生变化时继续处理。下拉选项的可见文字可以替换，`option.value` 提交值保持原样。

普通输入框的用户值、可编辑正文、`textarea` 正文、`code`、跨源 iframe、封闭 Shadow DOM 和网页 Canvas 不在处理范围内；可编辑控件的 `placeholder`、`title` 等支持的提示属性仍可处理。匹配以单个文本节点为单位，暂不支持把跨多个标签的文字拼成整句匹配。Java 与 JavaScript 的高级正则和日期格式可能存在差异。

**已有原生 TextView、菜单、通知、Canvas、自绘及资源字符串，仍需下一次赋值/渲染等事件才能重算。** 暂停不承诺立即撤销这些通道已经显示的历史文字。安装时关闭的通道在重新开启后仍需重启目标应用安装对应 Hook。

### 屏幕取词

在目标应用中直接点选文字创建规则，免去手动输入：

1. 规则页菜单 →「屏幕取词」→ 首次使用按提示开启无障碍服务「**GText屏幕取词**」
2. 再次点击「屏幕取词」，应用自动退到后台
3. 切换到目标应用，点击屏幕顶部的「**取词**」按钮
4. 在弹出的列表中点选文字，自动跳回 GText 预填创建规则

> 只能读取系统无障碍接口可见的文字，部分自绘界面可能读不到。

**取词服务自动恢复**：Android / MIUI 在应用被强行停止（划掉最近任务）后会自动关闭其无障碍服务（系统行为）。授予 GText **Root** 后，打开 GText 或使用取词时会通过 Root 自动重新启用该服务，无需再手动去无障碍设置授权。未授权 Root 时可将其锁定在最近任务、省电策略设为「无限制」以减少被关闭。

### 替换系统界面文字

1. 在 LSPosed 中将「系统界面（SystemUI）」「设置」等勾选进 GText 作用域
2. 在 GText 中添加对应应用（如"系统界面"，包名 `com.android.systemui`）并添加规则
3. 使用规则页菜单的「**重启该应用**」（需 Root）。GText 会先等待配置发布，再尝试重启；系统界面可能短暂黑屏闪烁

### 快捷磁贴（一键暂停）

下拉通知栏 → 编辑磁贴 → 添加「**GText 替换开关**」：

- 点击保存暂停/恢复设置；目标应用接收配置后，网页 DOM 恢复/重新计算，其他通道等待后续渲染事件
- 适合临时给别人看手机、截图等场景

### 备份 / 恢复

设置页 →「备份配置」导出应用规则、全局规则、各应用启停与通道设置，以及暂停替换、激活提示、深度模式三个替换设置。桌面图标隐藏状态、自动检查更新设置和系统无障碍授权不包含在备份中。

「恢复配置」先完整检查文件，再保存替换配置。任何应用或规则存在结构/正则错误时，整次恢复失败，原数据保持不变。兼容旧版备份。文件中缺失的应用规则段、全局规则段或替换设置项保留本地值；明确提供空数组则清空对应规则段。提供的规则段整体替换，不执行规则合并。

旧备份缺失或重复的规则标识会在导入时规范化，保留规则内容与顺序。如果本机配置已损坏而无法读取，恢复时需要同时包含应用规则、全局规则和完整替换设置的备份，避免用默认值补齐未知数据。

### 排查"为什么没替换"

1. **检查替换范围**：规则页菜单 →「替换范围」，确认该类文字所在的通道（菜单 / 通知 / H5 / 自绘）没有被关闭
2. **开启深度模式**：设置页 →「深度模式」打开，重启目标应用后再试（覆盖资源字符串入口）
3. **无效规则**：无效正则在保存时即会提示并保留编辑内容，修正后再保存

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 规则不生效 | 检查 LSPosed 作用域是否勾选；规则是否启用；等几秒让热更新生效，或重启目标应用 |
| 设置/开关不生效 | 重新打开一次 GText（会自动通过 LSPosed 服务通道同步）；或给 GText 授权 Root 启用 tmp 兜底通道 |
| 应用闪退 | 停用该应用总开关排查；删除最近添加的规则 |
| 某个页面怎么都不替换 | 先查「替换范围」是否关闭了对应通道；再开「深度模式」并重启应用；若为 Flutter/游戏引擎自绘则无法替换（见[支持范围](#支持范围)） |
| 不想看到目标应用的激活提示 | 设置页 →「启动时显示激活提示」关闭 |
| 打开 GText 为什么还有 Root 说明 | 规则升级提醒已取消；Root 说明是原有独立提示，未授权时按安装版本显示一次 |
| 应用出现异常/参数错乱 | 关闭「深度模式」；或调小该应用的「替换范围」，然后重启该应用 |
| 划掉后台后无障碍授权丢失 | 这是 Android/MIUI 的系统行为（应用被强停后其无障碍服务会被关闭）。给 GText 授权 Root 后会自动恢复，无需手动开启 |

## 数据同步机制

规则、全局规则、应用开关、替换范围和设置作为一个带版本的完整配置保存。保存成功后，在后台依次发布到 LSPosed 官方服务通道与文件兜底通道，目标应用只接收完整配置，避免把新规则与旧开关拼在一起。

首页仍显示原有的通道、取词和 Root 三个信号灯。**通道灯只表示 LSPosed 服务是否连接，不代表每个目标应用都已加载当前配置。** 服务未连接时仍可能通过文件兜底同步。目标进程是否运行、是否已升级 Hook、作用域是否正确，都会影响接收。首次升级本版本后应重启目标应用一次。

LSPosed 服务通道不要求额外授予 GText Root；文件兜底与「重启该应用」需要 Root，文件兜底还需设备支持相应的文件锁能力。规则页的重启操作会等待当前配置发布，最多 5 秒；未发布时不会继续重启，并提供重试入口。同步失败时，本机已保存的规则仍然保留。

## 性能说明

- 规则按已确认的列表优先级匹配，每个配置版本维护独立缓存
- 远程通道监听配置变化，并每 3 秒检查可读配置作为兜底；只有新版本才切换匹配器和网页规则
- Hook 按「替换范围」选择性安装：关闭 H5 / 自绘等类别时，对应 Hook 完全不安装，进一步降低开销
- 深度模式默认开启；如需极致轻量或遇到兼容问题，可在设置页关闭
- 全局规则只对已添加应用生效，未添加的应用在匹配入口快速返回
- 单条替换结果超过 500 字会自动截断，避免超长文本破坏页面布局
- 替换文含 `{date}`、`{time}`、`{datetime}`、`{random}` 或自定义格式变量时不缓存展开后的结果；重新计算时使用当时的值
