## 功能介绍

GText 是一款基于 LSPosed 框架的 Android 文字替换模块：把其他应用界面上显示的文字替换成你想要的内容。**仅改变本机显示，不影响应用数据，其他人看不到。**

### 核心特性

| 特性 | 说明 |
|------|------|
| 🎯 **精确替换** | 原文完全匹配才替换，所见即所改 |
| 🔣 **正则表达式** | 批量命中相似文字，如 `\d+分钟前` 一条规则替换所有"N分钟前" |
| 🔡 **忽略大小写** | 英文规则不区分大小写，可与正则叠加 |
| ⚡ **规则热更新** | 改规则后**无需重启目标应用**，几秒内自动生效 |
| 🌐 **全局规则** | 一条规则对所有已添加应用生效，无需逐个添加 |
| 🖥️ **系统界面** | 支持替换状态栏、设置等系统界面文字（配合作用域） |
| 👆 **屏幕取词** | 无障碍悬浮取词：在目标应用中点选文字直接创建规则 |
| 🧭 **替换范围** | 按类别控制每个应用参与替换的范围：文字界面 / 菜单弹窗 / 通知媒体 / H5 / 自绘 |
| 🧠 **深度模式** | 额外覆盖资源字符串（Resources.getString）等深层入口，可随时关闭 |
| 🧹 **批量操作** | 一键全部启用 / 全部停用 / 清理停用规则 / 清空规则 |
| 🚫 **一键暂停** | 快捷设置磁贴暂停/恢复全部替换，几秒生效 |
| 🔀 **优先级排序** | 长按拖拽调整规则顺序，控制先替换谁 |
| 🔍 **拼音搜索** | 主页支持全拼/首字母搜索（搜 "jd" 找到"京东"），命中高亮 |
| 🔄 **检查更新** | 读取 GitHub 最新 Release 并展示版本、附件与更新日志；启动时 6 小时自动检查一次 |
| 🔬 **页面自检** | 分析当前页面渲染方式（原生 / H5 / Compose / Flutter），直接判断能否替换 |
| 🅰 **字母分组** | 首页按拼音首字母分组，右侧字母条快速定位 |
| 🎨 **替换样式** | 单条规则可设粗体 / 斜体 / 红色 |
| 🕒 **动态变量** | 替换文支持 `{date}` `{time}` `{datetime}` `{random}` |
| 🔢 **捕获组** | 正则替换支持 `$1`~`$9` 引用分组 |
| 💾 **备份恢复** | 全部规则与设置一键备份还原 |
| 🔁 **重启应用** | Root 下重启桌面/系统界面等系统应用，无需重启手机 |
| 🚫 **生效范围可控** | 单条规则开关、单应用总开关，全局规则只对已添加应用生效 |

### 应用场景

- 🌐 **本地化翻译**：将应用中的英文替换为中文或其他语言
- ✏️ **文本修正**：修正应用中的错别字或不当表述
- 🎨 **个性化定制**：自定义应用中的文字显示内容
- 🔧 **功能隐藏**：隐藏或修改不需要的功能入口文字

## 支持范围

> 覆盖能力**按渲染引擎划分，而不是按 App 划分**：只要页面走的是下列通道，任何 App 都自动生效，无需逐 App 适配。

### ✅ 已覆盖的文本通道

| 分类 | 覆盖内容 |
|------|---------|
| **原生控件** | TextView / EditText（setText 全部重载含 setTextKeepState、hint、append、setError）、Button、CheckBox、Switch、Chip 等子类 |
| **标题栏** | Toolbar、ActionBar（含 AppCompat）、CollapsingToolbarLayout、Activity / Dialog 标题 |
| **弹窗提示** | AlertDialog、MaterialAlertDialog、Snackbar、Toast、PopupMenu、Tooltip |
| **列表式弹窗** | AlertDialog.Builder.setItems / setSingleChoiceItems / setMultiChoiceItems 的选项条目 |
| **菜单项** | MenuItem.setTitle 全系列、Menu.add(group,id,order,title)（下拉/悬浮/设置菜单文字） |
| **提示条** | Snackbar 文本与操作按钮、Toast、长按提示气泡（setTooltipText） |
| **搜索框** | SearchView 提示语与查询提示 |
| **系统零散** | 快捷设置磁贴标签（Tile.setLabel）、视频软字幕（SubtitleTrack）、WebView loadData 的 HTML 文本（受「网页 H5」通道开关控制） |
| **播放器字幕** | ExoPlayer / Media3 `SubtitleView` 软字幕 |
| **设置页控件** | androidx Preference 标题与摘要、TextInputLayout 计数器/前后缀/占位/错误提示、MaterialDatePicker 标题 |
| **副标题** | Toolbar / ActionBar setSubtitle |
| **通知与媒体** | 通知标题/内容/大文本/多行（InboxStyle、BigTextStyle）、摘要与内容信息、**聊天式通知**（MessagingStyle 消息与发送人）、RemoteViews 桌面小组件与描述、**音乐元数据**（歌名/歌手/专辑）与**媒体按钮文字**、**长按图标快捷菜单** |
| **导航与标签** | TabLayout、TabHost、BottomNavigationView、NavigationView、ViewPager 标题 |
| **选择器** | DatePicker、TimePicker、NumberPicker |
| **开关类** | Switch / SwitchCompat / ToggleButton 的开与关文字 |
| **列表** | RecyclerView、ListView 等各类 Adapter、Spinner、AutoCompleteTextView |
| **输入** | TextInputLayout 浮动提示、SearchView 提示、TextSwitcher |
| **富文本** | SpannableStringBuilder.append / replace（聊天、评论、弹幕） |
| **系统入口** | **Resources.getText / getQuantityText**、**getString（深度模式）**、**getStringArray / getTextArray**、菜单、Notification |
| **H5 页面** | 系统 WebView（DOM + MutationObserver + **Shadow DOM**）、腾讯 X5/TBS、UC U4；支持文本节点、`placeholder`（含 textarea）、按钮/选项 `value`、页面 `title`、`img alt`、`title`/`aria-label`、同源 iframe、**WebChromeClient 标题回填** |
| **跨端框架** | Jetpack Compose（AnnotatedString + Builder.append）、Taro 跨端文本 |
| **大厂自绘** | 淘宝 DinamicX（FastText 系列）、京东 Silk（TNTextView / TNRichText）、淘宝底部导航 |
| **自绘兜底** | Canvas.drawText 全系列、StaticLayout、BoringLayout（单行自绘）、TextUtils.ellipsize（省略文本）、PrecomputedText（Android 9+ 预计算文本）、自绘控件自动探测 |
| **无障碍** | View.setContentDescription（部分应用用它显示文字） |
| **应用名称** | `PackageItemInfo.loadLabel`（最近任务、系统设置里的条目名）、`TaskDescription` 标题（最近任务卡片）——用替换规则改，不是改应用名本身 |

### ❌ 架构上无法覆盖

| 引擎 | 典型页面 | 原因 |
|------|---------|------|
| Flutter / FlutterBoost | 闲鱼「订单列表/详情」等 | 文本由 Flutter 引擎（Skia）在 C++ 层自绘，Java 层无拦截点 |
| Unicorn 等自绘引擎 | 淘宝「订单详情」 | native Skia 绘制，文本不经过任何 Java API |
| 游戏 / 视频字幕 | 各类游戏 | 像素级渲染 |
| WebView 画布模式 | 在线文档等 | Canvas 渲染，DOM 中无文本节点 |

**快速判断某页面能否替换**：`adb shell dumpsys activity top` 看视图树——若整屏只有一个 `SurfaceView` / `FlutterView` 而没有成片的 `TextView`，就是引擎级渲染，Hook 不可达。

## 安装与激活

1. **安装模块**
   - 从 [Releases](../../releases) 下载最新 APK 安装
2. **激活模块**
   - 打开 LSPosed 管理器 → 模块列表 → 勾选启用 GText
3. **授权 Root（建议但非必需）**
- 规则同步优先使用 LSPosed 官方服务通道，无需 Root 即可工作
- 授权 Root 可额外启用：tmp 兜底写入、「重启该应用」功能、无障碍服务自动恢复
- **首次安装或更新后首次启动，若未授权 Root 会弹窗说明有/无 Root 的区别**（强制 15 秒倒计时后可关闭），同一版本只提示一次；已授权 Root 则不弹
4. **配置作用域**
   - 在 GText 中添加应用时会**自动弹出 LSPosed 作用域申请**，一键确认即可
   - 也可稍后在 LSPosed 中手动勾选

## 使用说明

### 添加替换规则

1. 打开 GText，点右下角 **➕** 选择目标应用
2. 进入应用规则页，点击 **➕** 添加规则
3. 填写 **原文**（应用里显示的文字）和 **替换文**（想改成的内容）
4. 按需开启 **正则表达式** / **忽略大小写** 开关
5. 保存后**几秒内自动生效**（热更新），无需重启应用

**替换文支持的语法**

| 语法 | 说明 | 示例 |
|------|------|------|
| `$1`~`$9` | 正则捕获组引用 | 原文 `(\d+)元` → 替换文 `$1元红包` |
| `{date}` | 当前日期 | `2026-10-28` |
| `{time}` | 当前时间 | `20:15` |
| `{datetime}` | 日期 + 时间 | `2026-10-28 20:15` |
| `{random}` | 随机四位数 | `3167` |
| `{date:格式}` | 自定义日期格式 | `{date:yyyy年M月d日}` → `2026年10月28日` |
| `{time:格式}` | 自定义时间格式 | `{time:HH:mm:ss}` → `20:15:03` |
| `{datetime:格式}` | 自定义日期时间格式 | `{datetime:MM/dd HH:mm}` → `10/28 20:15` |

**替换样式**：规则编辑页可选择「默认 / 粗体 / 斜体 / 红色」，让替换后的文字有视觉强调。

**宽松匹配（自动兜底）**：有些页面文字"看起来一样却匹配不上"，通常是夹带了零宽字符、全角/半角混排或 NBSP 空格。GText 会先用原文正常匹配，**只有在原文完全没命中时**才做一次归一化（去零宽、统一全半角与空格）再匹配一次，命中后按字符位置映射回原文替换。原本能命中的规则行为完全不变，也不产生额外开销。

### 管理规则

| 操作 | 方式 |
|------|------|
| 启用/停用单条 | 规则卡片左侧开关（停用后半透明显示） |
| 停用整个应用 | 应用列表右侧开关（规则保留，随时恢复） |
| 调整优先级 | 规则列表中**长按拖拽**排序（搜索过滤时禁用） |
| 编辑 / 删除 | 规则卡片右侧按钮 |
| 搜索 | 各页顶部搜索框；主页支持拼音/首字母 |
| 去重保护 | 添加重复原文时询问「覆盖 / 仍然添加」 |
| 批量操作 | 规则页菜单 →「批量操作」：全部启用 / 全部停用 / 删除已停用的规则 / 清空所有规则 |
| 长按卡片 | 复制该条规则原文 |
| 撤销删除 | 删除规则 / 应用后，底部提示条点「撤销」恢复 |
| 搜索高亮 | 规则列表搜索时命中文字高亮 |

### 替换范围（每应用通道开关）

应用规则页菜单 →「替换范围」，可分别控制该应用哪些类别参与替换：

| 范围 | 覆盖内容 |
|------|----------|
| 文字界面 | 文本框、标题、对话框等常规文字 |
| 菜单与列表弹窗 | 下拉菜单、悬浮菜单、列表式弹窗条目 |
| 通知、媒体、快捷菜单 | 通知文字、歌名歌手、长按图标菜单 |
| 网页 H5 | 网页文本、输入框提示、页面标题 |
| 自绘文字 | Canvas 绘制的文字等 |

默认全部开启。某类文字导致异常时可单独关闭；**改动需重启目标应用**才完全生效（Hook 按范围安装）。

### 设置页

右上角菜单 →「**设置**」，集中管理全部开关与数据操作：

| 分区 | 内容 |
|------|------|
| 生效设置 | 暂停全部替换、启动激活提示、深度模式（原「替换管理」分区已移除，全局规则移到首页） |
| 生效设置 | **暂停全部替换**（与下拉磁贴双向同步）、**启动时显示激活提示**、**深度模式** |
| 数据管理 | **备份配置**、**恢复配置** |
| 其他 | **检查更新**（读取 GitHub 最新版本，含更新日志与下载入口）、**关于 GText**（版本号、作者链接） |

> 首页顶部只有一行信息：左侧统计（应用 / 规则 / 全局），右侧三个状态圆点（**通道** / **取词** / **Root**），绿色正常、红色异常，**点击圆点可查看该项说明**。搜索框默认收起，点工具栏放大镜展开。

> **深度模式**（默认开启）：额外拦截 `Resources.getString` 等资源字符串入口，能覆盖更多界面文字。它会更深地介入应用逻辑，个别应用如出现显示或参数异常，先关闭它并重启应用。

### 全局规则

首页列表顶部「全局规则」卡片：对所有**已添加且未停用**的应用统一生效，适合替换多个应用中相同的文字。
> 只在 GText 中添加过的应用才会应用全局规则；仅勾选 LSPosed 作用域但未添加的应用不会被替换。

### 页面自检

规则页菜单 →「页面自检」→ 切到目标应用 → 点顶部「自检」：自动统计页面节点与特征（WebView / ComposeView / FlutterView / SurfaceView 等），给出「能否替换 + 应走哪条通道」的结论，用于排查"这个页面为什么改不了"。

### 屏幕取词

在目标应用中直接点选文字创建规则，免去手动输入：

1. 规则页菜单 →「屏幕取词」→ 首次使用按提示开启无障碍服务「**GText屏幕取词**」
2. 再次点击「屏幕取词」，应用自动退到后台
3. 切换到目标应用，点击屏幕顶部的「**取词**」按钮
4. 在弹出的列表中点选文字，自动跳回 GText 预填创建规则

> 只能读取系统无障碍接口可见的文字，部分自绘界面可能读不到。

**取词服务自动恢复**：Android / MIUI 在应用被强行停止（划掉最近任务）后会自动关闭其无障碍服务（系统行为）。授予 GText **Root** 后，打开 GText 或使用取词时会通过 Root 自动重新启用该服务，无需再手动去无障碍设置授权。未授权 Root 时可将其锁定在最近任务、省电策略设为「无限制」以减少被关闭。

### 替换系统界面文字

1. 在 LSPosed 中将「系统界面（SystemUI）」「设置」等勾选进 GText 作用域
2. 在 GText 中添加对应应用（如"系统界面"，包名 `com.android.systemui`）并添加规则
3. 用该应用规则页菜单的「**重启该应用**」立即生效（需 Root，免重启手机；系统界面会短暂黑屏闪烁，属正常现象）

### 快捷磁贴（一键暂停）

下拉通知栏 → 编辑磁贴 → 添加「**GText 替换开关**」：
- 点击一键暂停/恢复全部替换，几秒生效，无需重启应用
- 适合临时给别人看手机、截图等场景

### 备份 / 恢复

设置页 →「备份配置」导出全部规则与设置为文件；「恢复配置」一键还原。换机、重装或重置 LSPosed 后使用。

### 排查"为什么没替换"

1. **检查替换范围**：规则页菜单 →「替换范围」，确认该类文字所在的通道（菜单 / 通知 / H5 / 自绘）没有被关闭
2. **开启深度模式**：设置页 →「深度模式」打开，重启目标应用后再试（覆盖资源字符串入口）
3. **无效规则**：无效正则在保存时即会提示，被忽略的规则不会生效，注意检查语法

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 规则不生效 | 检查 LSPosed 作用域是否勾选；规则是否启用；等几秒让热更新生效，或重启目标应用 |
| 设置/开关不生效 | 重新打开一次 GText（会自动通过 LSPosed 服务通道同步）；或给 GText 授权 Root 启用 tmp 兜底通道 |
| 应用闪退 | 停用该应用总开关排查；删除最近添加的规则 |
| 某个页面怎么都不替换 | 先查「替换范围」是否关闭了对应通道；再开「深度模式」并重启应用；若为 Flutter/游戏引擎自绘则无法替换（见[支持范围](#支持范围)） |
| 不想看到启动提示 | 设置页 →「启动时显示激活提示」关闭 |
| 应用出现异常/参数错乱 | 关闭「深度模式」；或调小该应用的「替换范围」，然后重启该应用 |
| 划掉后台后无障碍授权丢失 | 这是 Android/MIUI 的系统行为（应用被强停后其无障碍服务会被关闭）。给 GText 授权 Root 后会自动恢复，无需手动开启 |

## 数据同步机制

GText 在应用与 Hook 端之间同步规则有多条通道，Hook 端启动时**自动探测并选择**可用通道：

| 优先级 | 通道 | 说明 |
|--------|------|------|
| 1 | **LSPosed 远程偏好**（官方服务） | 应用侧通过 XposedService 推送全部规则与设置，Hook 端读取；不怕清理软件、免 Root，**推荐主通道** |
| 2 | 模块 prefs 文件 | 兼容备用通道 |
| 3 | `/data/local/tmp` 镜像文件 | 兜底通道；目录对应用只读，创建新文件需要 Root，且可能被清理软件删除 |

说明：

- 规则、全局规则、各类开关（含替换范围、深度模式）均会实时同步到远程通道，修改后几秒内生效
- **首页顶部「通道」状态 = 第 1 条通道是否已连接**：绿色已连接（推荐）；红色未连接时自动退回第 3 条兜底通道，替换通常仍可用，但文件被清理或未授权 Root 时会失效
- 因此仍建议给 GText 授权 Root：兜底通道写入、「重启该应用」功能依赖 Root；不授权也能正常使用替换

## 性能说明

- 规则按首字符索引 + 结果缓存匹配，UI 渲染时替换，运行时开销可忽略
- 热更新轮询为 3 秒一次的文件签名检查（读取修改时间），几乎零开销
- Hook 按「替换范围」选择性安装：关闭 H5 / 自绘等类别时，对应 Hook 完全不安装，进一步降低开销
- 深度模式默认开启；如需极致轻量或遇到兼容问题，可在设置页关闭
- 全局规则只对已添加应用生效，未添加的应用零开销
- 单条替换结果超过 500 字会自动截断，避免超长文本破坏页面布局
- 替换文含 `{date}` 等动态变量时不做结果缓存，保证日期/随机数实时刷新
