


## 功能介绍

GText 是一款基于 LSPosed 框架的 Android 文本替换模块，允许用户自定义替换任意应用中的文本内容。

### 核心功能

| 功能 | 描述 |
|------|------|
| **应用规则** | 针对特定应用设置独立的文本替换规则 |
| **全局规则** | 设置全局生效的文本替换规则，对所有应用生效 |
| **生效时效** | 保存规则后，重新打开应用即可生效 |
| **规则管理** | 支持添加、编辑、删除规则，支持查看规则数量统计 |
| **应用搜索** | 快速搜索和筛选已安装应用 |
| **作用域申请** | 添加应用时自动弹出 LSPosed 作用域申请 |

### 应用场景

- 🌐 **本地化翻译**：将应用中的英文替换为中文或其他语言
- ✏️ **文本修正**：修正应用中的错别字或不当表述
- 🎨 **个性化定制**：自定义应用中的文字显示内容
- 🔧 **功能隐藏**：隐藏或修改不需要的功能入口文字

## 使用说明

### 安装步骤

1. **安装模块**
   - 下载并安装 GText APK
2. **激活模块**
   - 打开 LSPosed 管理器
   - 在模块列表中找到 GText
   - 勾选启用模块

3. **配置作用域**
   - 在 LSPosed 中为 GText 勾选需要修改的目标应用
   - 或在 GText 中添加应用时自动弹出作用域申请

### 添加规则

1. 打开 GText 模块应用
2. 点击右下角 **添加应用** 按钮
3. 在应用列表中选择目标应用
4. 点击 **添加规则** 创建新的替换规则
5. 输入 **原文本** 和 **替换文本**
6. 点击 **保存** 按钮

### 管理规则

- **查看规则**：在应用详情页查看所有规则
- **编辑规则**：点击规则项进行编辑
- **删除规则**：长按规则项或点击删除按钮
- **全局规则**：在首页点击 **全局规则** 添加对所有应用生效的规则

### 规则生效

- 保存规则后，重新打开目标应用，规则即可生效
- 如未生效，请尝试重启目标应用或重启设备

## 注意事项

### 使用前须知

- ⚠️ **Root 权限**：本模块需要 Root 权限和 LSPosed 框架(API 101)支持
- ⚠️ **数据备份**：使用前请备份重要数据，以防意外情况
- ⚠️ **系统应用**：修改系统应用文本可能导致系统不稳定，请谨慎操作
- ⚠️ **规则冲突**：多条规则可能产生冲突，请检查规则设置

### 常见问题

| 问题 | 解决方案 |
|------|----------|
| 规则不生效 | 检查 LSPosed 作用域是否正确勾选；重启目标应用或设备 |
| 模块不显示 | 确认 LSPosed 版本（API 101）；重启设备 |
| 应用闪退 | 检查规则是否导致应用异常；删除相关规则 |
| 无法添加应用 | 检查 LSPosed 是否正确授权 |

### 性能影响

- 模块在目标应用启动时会加载规则，对启动速度影响极小
- 文本替换在 UI 渲染时进行，对运行时性能影响可忽略
- 建议不要添加过多全局规则，以保持最佳性能
